   - Usa: Auditoría seguridad pre-push
   - Impacto: Prevents vulnerabilities antes de PROD

## 🔄 FLUJO DE TRABAJO FORMALIZADO (GStack)

```
1. THINK          → /office-hours (ideate + forcing questions)
                    ↓
2. PLAN           → /plan-ceo-review (strategy)
                  → /plan-eng-review (architecture)
                  → /plan-design-review (UX/UI)
                    ↓
3. BUILD          → Código (usando agentes + skills)
                    ↓
4. REVIEW         → /review (code quality)
                  → /design-review (design QA)
                    ↓
5. TEST           → /qa (browser real + auto-fix)
                  → /cso (security audit)
                    ↓
6. SHIP           → /ship (PR + deploy)
                  → /document-release (changelog)
                    ↓
7. REFLECT        → /retro (lessons learned)
```
